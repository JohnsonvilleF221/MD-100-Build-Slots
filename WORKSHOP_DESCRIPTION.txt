[h1]MD 100 Build Slots[/h1]

A [b]Millennium Dawn[/b] submod that lets populous states actually build like populous states. Stock MD tops out at [b]50[/b] base building slots for a 65m+ state and clamps the engine ceiling at [b]56[/b]. This raises the population ramp to [b]85[/b] and lifts the hard cap to [b]100[/b], leaving room for railway and infrastructure modifiers to stack on top.

[h2]What changes[/h2]

MD gives every state a category based on its population, and that category sets the state's shared building-slot base. This submod re-tunes the top ten categories and leaves everything below them alone:

[h2]Compatibility[/h2]

Built for HOI4 1.19.x and Millennium Dawn 2.0. Load Millennium Dawn first and this submod last. The launcher sorts this out for you, since MD's Beta Test, Modern Day and Developer Version are all listed as dependencies.

It replaces MD's building slot categories and two of its interface files, so it will clash with any other submod that changes building slots or the state screen.

Not save game compatible.
